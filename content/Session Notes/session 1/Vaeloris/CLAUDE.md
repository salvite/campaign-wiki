# Vaeloris Campaign Notes - Instructions

## Purpose
This folder contains in-depth D&D campaign notes for the Vaeloris campaign. The user will provide quick, informal updates and I will modify the appropriate files accordingly.

## Core Rule: Never Delete or Compress Information
- Updates are **additive only**. Never remove, overwrite, summarize, or compress existing content in any file.
- New information gets **appended** to the relevant section or added as a new section/row.
- If new info contradicts old info, add the new info alongside the old -- do not replace. Note the contradiction if appropriate.
- If a section is empty (placeholder dashes in tables, template brackets), it is fine to replace those placeholders with real content.

## How Updates Work
- The user will give quick, informal updates (e.g. "we met a new NPC named Draven in the Crucible District" or "session 3: the party fought goblins in the Stoneward tunnels").
- I identify which files need updating and append the new information to the correct sections.
- If a new file is needed (new character, location, quest, etc.), create one from the relevant `_template.md`.
- Always update cross-references: if a new NPC appears in a session, update both the session file and the character file's Session Appearances table.
- Update the INDEX.md tables when new files are created.

## File Structure
- `INDEX.md` - Master navigation hub
- `Sessions/` - Chronological session logs (copy `_template.md` for new sessions)
- `Characters/` - Individual NPC/PC reference files
- `Locations/` - Place descriptions
- `Factions/` - Organizations, nations, guilds (guilds in `Factions/Guilds/`)
- `Lore/` - World lore, history, magic, prophecy
- `Quests/` - Active and completed quests
- Each folder has a `_template.md` for consistent formatting
